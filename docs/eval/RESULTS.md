## Our own suites (generalisation checks)

| Suite | Items | Built how | Final | Accuracy |
|---|---|---|---|---|
| `dev_eval.jsonl` | 30 | as-of and current-value items from rate-sheet diffs across snapshots, rewordings, tiers, 6 refusals | 0.949 | 1.000 |
| `dev2_blind.jsonl` | 18 | written and value-checked against raw pages **before** the system was run on it | 0.856 | 0.891 |
| kit selftest | 5 | synthetic second site shipped in `harness/selftest` | 1.000 | 1.000 |

Read these honestly:

- The dev set was used for tuning after its first run (0.797). Treat it as a regression suite, not a held-out score.
- The blind set scored **0.800 on its first run**. 0.856 is after fixing what it exposed (fee-schedule tables,
  "10 years" = "120 months", open-ended amount ranges, phone-number questions). Two items still fail: a boat
  loan below the smallest tier (an ATV table without amount tiers answers instead of a refusal), and "what number
  do I call if my card is lost" (a PIN-setup number outranks the lost-card number).
- The selftest exposed three generalisation bugs that the public set hides: a refusal threshold tied to corpus
  size, pages missing from a later crawl, and `label: value` facts. It scored 0.178 before the fixes.

## Conflicts

`conflicts()` returns 32 entries. Against our gold list (`conflicts_gold.json`, 12 contradictions built by hand
from raw snapshot diffs): recall 12/12, resolution accuracy 0.92 (the one miss is the scorer's greedy matcher
pairing the jumbo 10-month gold entry with the non-jumbo 10-month conflict, which shares the 3.90% value), and
precision 0.375 (our gold is deliberately small; the organisers' hidden list is likely larger).

Kinds found: stale rate tables on secondary pages (`/homebuying-guidance`, `/mortgage-refi`, `/switch-and-earn`,
the vehicle calculator, checking-offer landing pages), rate-sheet changes across snapshots (certificate specials,
mortgages, auto tiers), branch counts in old press-release boilerplate (19/20/23/24 vs 22), and the Forbes
"fourth/fifth time" releases.

## Known misses on the public set (not hard-coded, by design)

- dup-005: `must_include` is empty, so the scorer gives 0 to any answer without the LLM judge.
- dup-049, dup-081, dup-060, dup-088, dup-031, dup-094, dup-087, dup-008: the expected answer needs synthesis
  across passages ("no tier pays 0.35%"), a fact from a different paragraph than the best lexical match, or a
  link target rather than page text. These are what the phase-2 LLM flag is for.
